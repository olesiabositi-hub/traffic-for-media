# Пробки для эфира

Прототип для хакатона: автоматическая аналитика пробок для радио и СМИ. Редакция открывает страницу города и сразу получает готовый текст для эфира со ссылкой на 2ГИС как источник. Ничего не нужно уточнять или переписывать.

> Все цифры, улицы и фото в прототипе демонстрационные.

## Как запустить

Откройте `index.html` в браузере. Сборка и сервер не нужны.

Чтобы получить ссылку для жюри, включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Что внутри

### Базовый минимум
- Общая длина пробок в км и доля от всех дорог города.
- Топ-10 пробок. У каждой указаны улица, участок «от и до», скорость, длина и время проезда.
- Мосты, центр и главные улицы. Список задаётся для каждого города один раз.
- Топ-5 нетипичных пробок с причиной: ДТП, дорожные работы, затопление, снег и лёд.
- История за сегодня, неделю, месяц и год. Сортировка по длине, продолжительности, скорости и баллам.
- Подписка на сводку с выбором частоты и содержания, а также превью письма.

### УТП: чего нет у конкурента
- **Текст под хронометраж**: 10 секунд, 30 секунд, новость для сайта, пост для соцсетей.
- **Совет, как объехать, с выигрышем во времени**: «лучше по Бугринскому мосту, быстрее на 19 минут».
- **Сравнение с обычным днём недели и прогноз** на ближайшие часы.
- **Рекорды с контекстом**: «самая долгая пробка месяца — первый снег».
- **Фото с дорог от пользователей** с готовой подписью для СМИ.
- **Озвучка сводки** синтезированным голосом. Она нужна небольшим и сетевым станциям, которые утром работают на автоматике без ведущего, а также подкастам, голосовым ассистентам и аудио в Telegram: готовый звуковой файл ставится в сетку автоматически. Ещё озвучка помогает редактору проверить хронометраж на слух. Крупным станциям со своими ведущими хватает текста, поэтому это дополнительная функция, а не главная.
- **Мгновенные алерты** о ДТП и нетипичных пробках.
- **Виджет для сайта и JSON API** для эфирного софта.
- **Экономика пробок**: сколько часов город простоял с утра.
- Идеи на развитие: районные сводки, связка с погодой и афишей событий.

## Как устроено

Одна страница: `index.html` (HTML, CSS и JS без зависимостей). Данные городов лежат в объекте `CITIES`. Тексты для эфира собираются шаблонами в объекте `FORMATS`, с правильными склонениями («1 балл», «3 балла», «8 баллов»).

Чтобы подключить реальные данные, замените `CITIES` ответом API пробок. Шаблоны текстов и вёрстка останутся без изменений.
